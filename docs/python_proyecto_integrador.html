67  🧩 Proyecto integrador: atlas de cónicas rotadas

Fecha de entrega: por definir

En Geometría Analítica estudiaron las cónicas (elipse, parábola e hipérbola) y aprendieron que una ecuación de segundo grado con término \(xy\) representa una cónica rotada. En este proyecto construirán, en equipo, un sitio web que analice una de esas cónicas usando todo lo que aprendimos en el Taller de Cómputo: Python, SymPy, NumPy, visualización, transformaciones geométricas, números aleatorios, Quarto, Git y GitHub.

67.1 Objetivo

Analizar la cónica

\[Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0\]

que le corresponda a su equipo: clasificarla, eliminar el término \(xy\) mediante una rotación de ejes, obtener su forma canónica y sus elementos, visualizarla en 2D y 3D, comprobar su definición como lugar geométrico, estimar un área con el método de Monte Carlo y publicar todo en un sitio web de Quarto en GitHub Pages.

67.4 Ejemplo resuelto: \(5x^2 - 6xy + 5y^2 - 8 = 0\)

Código 
import numpy as np
import matplotlib.pyplot as plt
import sympy as sp

x, y, u, v = sp.symbols("x y u v", real=True)
ecuacion = 5*x**2 - 6*x*y + 5*y**2 - 8

67.4.1 Parte 2. Funciones del proyecto

Escribimos funciones reutilizables, con docstring y validación, siguiendo el capítulo de funciones:

Código 
def coeficientes(expresion):
    """Regresa los coeficientes A, B, C, D, E, F de Ax² + Bxy + Cy² + Dx + Ey + F."""
    P = sp.Poly(expresion, x, y)
    monomios = [x**2, x*y, y**2, x, y, 1]
    return [P.coeff_monomial(m) for m in monomios]


def clasificar_conica(A, B, C):
    """Clasifica la cónica según el discriminante B² - 4AC."""
    if A == 0 and B == 0 and C == 0:
        raise ValueError("No es una ecuación de segundo grado: A, B y C son cero")
    discriminante = B**2 - 4*A*C
    if discriminante < 0:
        return "elipse"
    elif discriminante == 0:
        return "parábola"
    else:
        return "hipérbola"


def angulo_rotacion(A, B, C):
    """Ángulo θ (en radianes) que elimina el término xy: tan(2θ) = B / (A - C)."""
    if B == 0:
        return 0
    if A == C:
        return sp.pi / 4
    return sp.atan(B / (A - C)) / 2

Y las probamos con casos conocidos, como en el capítulo de funciones:

Código 
assert clasificar_conica(1, 0, 1) == "elipse"        # x² + y² = r²
assert clasificar_conica(0, 0, 1) == "parábola"      # y² = 4px
assert clasificar_conica(1, 0, -1) == "hipérbola"    # x² - y² = 1
assert clasificar_conica(0, 1, 0) == "hipérbola"     # xy = 4
assert angulo_rotacion(1, 0, 4) == 0                 # Sin término xy: no hay que rotar
assert angulo_rotacion(0, 1, 0) == sp.pi / 4         # xy = 4 se rota 45°
print("Todas las pruebas pasaron ✅")
Todas las pruebas pasaron ✅

67.4.2 Parte 3. Análisis algebraico

Clasificación y ángulo de rotación:

Código 
A, B, C, D, E, F = coeficientes(ecuacion)
print("Coeficientes:", A, B, C, D, E, F)
Coeficientes: 5 -6 5 0 0 -8
Código 
print("Discriminante B² - 4AC =", B**2 - 4*A*C, "→", clasificar_conica(A, B, C))
Discriminante B² - 4AC = -64 → elipse
Código 
theta = angulo_rotacion(A, B, C)
print("Ángulo de rotación:", theta, "=", sp.deg(theta), "grados")
Ángulo de rotación: pi/4 = 45 grados

Rotación de ejes. Sustituimos \(x = u\cos\theta - v\sin\theta\) y \(y = u\sin\theta + v\cos\theta\):

Código 
x_rot = u*sp.cos(theta) - v*sp.sin(theta)
y_rot = u*sp.sin(theta) + v*sp.cos(theta)

rotada = sp.expand(ecuacion.subs({x: x_rot, y: y_rot}, simultaneous=True))
print(rotada, "= 0")
2*u**2 + 8*v**2 - 8 = 0

El término \(uv\) desapareció. Dividiendo entre 8 se obtiene la forma canónica:

Código 
canonica = sp.expand((rotada + 8) / 8)
print(canonica, "= 1")
u**2/4 + v**2 = 1

\[\frac{u^2}{4} + \frac{v^2}{1} = 1\]

Elementos. Es una elipse con centro en el origen y eje mayor sobre el eje \(u\):

Código 
a, b = 2, 1
c = sp.sqrt(a**2 - b**2)
print("a =", a, " b =", b, " c =", c, " excentricidad e =", c / a)
a = 2  b = 1  c = sqrt(3)  excentricidad e = sqrt(3)/2
Código 
R = sp.Matrix([[sp.cos(theta), -sp.sin(theta)], [sp.sin(theta), sp.cos(theta)]])
for nombre, punto in [("Vértice", (a, 0)), ("Vértice", (-a, 0)), ("Foco", (c, 0)), ("Foco", (-c, 0))]:
    original = sp.simplify(R * sp.Matrix(punto))
    print(f"{nombre} {punto} en (u, v)  →  {tuple(original)} en (x, y)")
Vértice (2, 0) en (u, v)  →  (sqrt(2), sqrt(2)) en (x, y)
Vértice (-2, 0) en (u, v)  →  (-sqrt(2), -sqrt(2)) en (x, y)
Foco (sqrt(3), 0) en (u, v)  →  (sqrt(6)/2, sqrt(6)/2) en (x, y)
Foco (-sqrt(3), 0) en (u, v)  →  (-sqrt(6)/2, -sqrt(6)/2) en (x, y)

Para regresar un punto de las coordenadas \((u, v)\) a las originales \((x, y)\) multiplicamos por la matriz de rotación \(R(\theta)\): es la misma sustitución que usamos arriba, escrita como matriz.

67.4.4 Parte 5. Comprobación con una matriz de rotación

Tomamos la elipse canónica \(\frac{u^2}{4} + v^2 = 1\), la parametrizamos y la giramos \(\theta\) con la matriz \(R(\theta)\) de NumPy (transformaciones geométricas). Si el análisis es correcto, debe caer exactamente sobre la curva original:

Código 
s = np.linspace(0, 2 * np.pi, 200)
canonica_uv = np.vstack([2 * np.cos(s), 1 * np.sin(s)])    # u = a cos s, v = b sin s
girada = Rn @ canonica_uv

fig, axs = plt.subplots(1, 2, figsize=(10, 5))
for ax_ in axs:
    ax_.axhline(0, color="black", linewidth=0.8)
    ax_.axvline(0, color="black", linewidth=0.8)
    ax_.set_xlim(-3, 3); ax_.set_ylim(-3, 3)
    ax_.set_aspect("equal")
    ax_.grid(True, alpha=0.3)

axs[0].plot(canonica_uv[0], canonica_uv[1], color="tab:green")
axs[0].set_title("Forma canónica en $(u, v)$")

axs[1].contour(X, Y, Z, levels=[0], colors="tab:blue", linewidths=5, alpha=0.4)
axs[1].plot(girada[0], girada[1], "r--", label="Canónica girada con $R(\\theta)$")
axs[1].legend(loc="lower right", fontsize=8)
axs[1].set_title("Coincide con la ecuación original")
plt.show()
Código

Error máximo al sustituir en la ecuación original: 5.329070518200751e-15

67.4.5 Parte 6. Comprobación como lugar geométrico

Una elipse es el lugar geométrico de los puntos cuya suma de distancias a los dos focos es constante e igual a \(2a\). Lo comprobamos en los 200 puntos de la curva:

Código 
F1, F2 = f_xy[:, 0], f_xy[:, 1]
d1 = np.hypot(girada[0] - F1[0], girada[1] - F1[1])
d2 = np.hypot(girada[0] - F2[0], girada[1] - F2[1])
suma = d1 + d2

print("Suma mínima:", suma.min(), "  Suma máxima:", suma.max(), "  2a =", 2 * a)
Suma mínima: 3.999999999999999   Suma máxima: 4.000000000000001   2a = 4

np.hypot(dx, dy) calcula \(\sqrt{dx^2 + dy^2}\), la distancia entre dos puntos.

Cónica Definición como lugar geométrico Qué deben comprobar
Elipse \(d(P, F_1) + d(P, F_2) = 2a\) La suma es constante.
Hipérbola \(\lvert d(P, F_1) - d(P, F_2) \rvert = 2a\) La diferencia (en valor absoluto) es constante.
Parábola \(d(P, F) = d(P, \text{directriz})\) Ambas distancias son iguales.

67.4.6 Parte 7. Área con el método de Monte Carlo

El área de una elipse es \(\pi a b = 2\pi \approx 6.2832\). La estimamos lanzando puntos al azar en el cuadrado \([-3, 3] \times [-3, 3]\), que la contiene, y contando cuántos cumplen \(5x^2 - 6xy + 5y^2 - 8 < 0\), es decir, cuántos caen dentro (números aleatorios):

Código 
rng = np.random.default_rng(2026)
n = 200_000
px = rng.uniform(-3, 3, n)
py = rng.uniform(-3, 3, n)
dentro = 5*px**2 - 6*px*py + 5*py**2 - 8 < 0

area_cuadrado = 6 * 6
area_estimada = area_cuadrado * dentro.mean()
print(f"Monte Carlo (n = {n}): {area_estimada:.4f}   Exacta πab = {2 * np.pi:.4f}")
Monte Carlo (n = 200000): 6.2408   Exacta πab = 6.2832

La diferencia, de unas centésimas, se debe al azar: como vimos en números aleatorios, el error disminuye como \(1/\sqrt{n}\). En su proyecto incluyan una gráfica de convergencia que muestre cómo se acerca la estimación al valor exacto al aumentar \(n\).

Nota¿Por qué el área no cambia al rotar?

La matriz de rotación tiene determinante 1 (lo vimos en transformaciones geométricas): las rotaciones conservan las áreas. Por eso el área de la cónica rotada es la misma que la de su forma canónica, y se puede calcular con la fórmula de la forma canónica o con una integral en las coordenadas \((u, v)\).

67.5 Indicaciones para cada tipo de cónica

El ejemplo es una elipse centrada en el origen. Según la cónica de su equipo, tomen en cuenta lo siguiente:

Si su cónica… Hagan esto
Es una hipérbola Además de los focos y vértices, obtengan las asíntotas \(v = \pm\frac{b}{a}u\) y grafíquenlas (rotadas a las coordenadas \(x, y\)). Para Monte Carlo, estimen el área de la región entre una rama y el lado recto (la recta perpendicular al eje focal que pasa por el foco).
Es una parábola Obtengan el vértice, el foco y la directriz, y grafiquen los tres. Para Monte Carlo, estimen el área de la región entre la parábola y su lado recto; el valor exacto es \(\frac{8}{3}p^2\), donde \(p\) es la distancia del vértice al foco.
Tiene términos \(Dx\) o \(Ey\) Después de rotar quedarán términos de primer grado: completen el cuadrado (o trasladen el origen) para encontrar el centro o el vértice. Pueden usar sp.solve([sp.diff(G, u), sp.diff(G, v)], [u, v]), como en el ejercicio 4 de Visualización II.
Tiene un ángulo de rotación que no es “bonito” Trabajen con el valor exacto de SymPy y conviértanlo con float() solo para graficar.
TipMonte Carlo en coordenadas canónicas

Para las regiones de la hipérbola y la parábola es más fácil lanzar los puntos en las coordenadas \((u, v)\), donde la cónica está en forma canónica: el área es la misma porque la rotación la conserva. Después comparen con el valor exacto que obtengan con sp.integrate().

67.6.1 Calentamiento 1. Clasificar una cónica

NotaPista

El discriminante es B**2 - 4*A*C. Es parábola cuando el discriminante es cero: discriminante == 0.

TipSolución 
def clasificar_conica(A, B, C):
    """Clasifica la cónica Ax² + Bxy + Cy² + ... = 0 según el discriminante B² - 4AC."""
    discriminante = B**2 - 4*A*C
    if discriminante < 0:
        return "elipse"
    elif discriminante == 0:
        return "parábola"
    else:
        return "hipérbola"

67.6.2 Calentamiento 2. El ángulo de rotación

Completen angulo_rotacion(A, B, C) para que regrese el ángulo \(\theta\), en grados, que elimina el término \(xy\):

  • Si \(B = 0\), no hay que rotar: \(\theta = 0\).
  • Si \(A = C\), \(\theta = 45°\).
  • En otro caso, \(\theta = \frac{1}{2}\arctan\left(\frac{B}{A - C}\right)\).
NotaPista

La condición es A == C. Para el caso general: math.degrees(math.atan(B / (A - C))) / 2.

TipSolución 
def angulo_rotacion(A, B, C):
    """Ángulo θ (en grados) que elimina el término xy de Ax² + Bxy + Cy² + ... = 0."""
    if B == 0:
        return 0
    if A == C:
        return 45
    return math.degrees(math.atan(B / (A - C))) / 2

Para el equipo 1: \(\tan 2\theta = \frac{-6\sqrt{3}}{7 - 13} = \sqrt{3}\), así que \(2\theta = 60°\) y \(\theta = 30°\).

"""Funciones del proyecto integrador: atlas de cónicas rotadas."""
import numpy as np
import sympy as sp

x, y, u, v = sp.symbols("x y u v", real=True)


def coeficientes(expresion):
    """Regresa [A, B, C, D, E, F] de la cónica Ax² + Bxy + Cy² + Dx + Ey + F = 0."""
    P = sp.Poly(expresion, x, y)
    return [P.coeff_monomial(m) for m in (x**2, x*y, y**2, x, y, 1)]


def clasificar_conica(A, B, C):
    """Clasifica la cónica según el discriminante B² - 4AC."""
    if A == 0 and B == 0 and C == 0:
        raise ValueError("No es una ecuación de segundo grado: A, B y C son cero")
    discriminante = B**2 - 4*A*C
    if discriminante < 0:
        return "elipse"
    elif discriminante == 0:
        return "parábola"
    else:
        return "hipérbola"


def angulo_rotacion(A, B, C):
    """Ángulo θ exacto (radianes) que elimina el término xy: tan(2θ) = B / (A - C)."""
    if B == 0:
        return sp.Integer(0)
    if A == C:
        return sp.pi / 4
    return sp.atan(sp.nsimplify(B) / sp.nsimplify(A - C)) / 2


def rotar_ecuacion(expresion, theta):
    """Sustituye x = u cos θ - v sin θ, y = u sin θ + v cos θ y simplifica."""
    sustitucion = {x: u*sp.cos(theta) - v*sp.sin(theta),
                   y: u*sp.sin(theta) + v*sp.cos(theta)}
    return sp.expand(sp.simplify(expresion.subs(sustitucion, simultaneous=True)))


def matriz_rotacion(theta):
    """Matriz de rotación de NumPy (2 × 2) para un ángulo theta en radianes."""
    t = float(theta)
    return np.array([[np.cos(t), -np.sin(t)],
                     [np.sin(t),  np.cos(t)]])


def plano_cartesiano(ax, limite=3):
    """Prepara ax como plano cartesiano: ejes en el origen, misma escala y cuadrícula."""
    ax.axhline(0, color="black", linewidth=0.8)
    ax.axvline(0, color="black", linewidth=0.8)
    ax.set_xlim(-limite, limite)
    ax.set_ylim(-limite, limite)
    ax.set_aspect("equal")
    ax.grid(True, alpha=0.3)

## Parámetros

```{python}
import numpy as np
import matplotlib.pyplot as plt

SEMILLA = 2026
N_PUNTOS = 200_000
LADO = 3                     # Lanzamos puntos en el cuadrado [-3, 3] × [-3, 3]
AREA_EXACTA = 2 * np.pi      # πab con a = 2, b = 1

rng = np.random.default_rng(SEMILLA)
```

## Estimación

Un punto $(x, y)$ está **dentro** de la elipse si $5x^2 - 6xy + 5y^2 - 8 < 0$. El área es la fracción de puntos dentro, multiplicada por el área del cuadrado:

$$\text{Área} \approx (2 \cdot 3)^2 \cdot \frac{\text{puntos dentro}}{\text{puntos totales}}$$

```{python}
px = rng.uniform(-LADO, LADO, N_PUNTOS)
py = rng.uniform(-LADO, LADO, N_PUNTOS)
dentro = 5*px**2 - 6*px*py + 5*py**2 - 8 < 0

area_estimada = (2 * LADO)**2 * dentro.mean()
error = abs(area_estimada - AREA_EXACTA)
```

Con `{python} f"{N_PUNTOS:,}"` puntos, el área estimada es **`{python} f"{area_estimada:.4f}"`**, mientras que el área exacta es $2\pi \approx$ `{python} f"{AREA_EXACTA:.4f}"`: un error de `{python} f"{error:.4f}"`.

```{python}
#| label: fig-puntos
#| fig-cap: "Los primeros 5000 puntos: en azul los que caen dentro de la elipse."
m = 5000
fig, ax = plt.subplots(figsize=(5, 5))
ax.scatter(px[:m][dentro[:m]], py[:m][dentro[:m]], s=2, color="tab:blue", label="Dentro")
ax.scatter(px[:m][~dentro[:m]], py[:m][~dentro[:m]], s=2, color="lightgray", label="Fuera")
ax.set_aspect("equal")
ax.legend(loc="lower right")
plt.show()
```

## Convergencia

```{python}
#| label: fig-convergencia
#| fig-cap: "El error de la estimación disminuye como $1/\\sqrt{n}$."
tamanos = np.logspace(2, 6, 9).astype(int)
errores = []
for n in tamanos:
    qx = rng.uniform(-LADO, LADO, n)
    qy = rng.uniform(-LADO, LADO, n)
    estimacion = (2 * LADO)**2 * np.mean(5*qx**2 - 6*qx*qy + 5*qy**2 - 8 < 0)
    errores.append(abs(estimacion - AREA_EXACTA))

fig, ax = plt.subplots(figsize=(7, 4))
ax.loglog(tamanos, errores, "o-", label="Error de la estimación")
ax.loglog(tamanos, 10 / np.sqrt(tamanos), "r--", label="Referencia $1/\\sqrt{n}$")
ax.set_xlabel("Número de puntos $n$")
ax.set_ylabel("Error absoluto")
ax.legend()
plt.show()
```

Como muestra la @fig-convergencia, para reducir el error 10 veces se necesitan aproximadamente 100 veces más puntos.

::: callout-note
La rotación **no cambia el área**: la matriz de rotación tiene determinante 1. Por eso el área de la elipse rotada es igual a la de su forma canónica, $\pi a b$.
:::

## Lo que aprendimos

- El **discriminante** $B^2 - 4AC = -64$ permitió clasificar la cónica como una **elipse** sin graficarla.
- Una **rotación de 45°** eliminó el término $xy$ y llevó la ecuación a su forma canónica $\frac{u^2}{4} + v^2 = 1$.
- La **matriz de rotación** de NumPy confirmó el resultado: la elipse canónica girada coincide con la ecuación original con un error de $10^{-15}$.
- Comprobamos numéricamente la **definición** de la elipse: la suma de distancias a los focos es $2a = 4$ en todos los puntos.
- El **método de Monte Carlo** estimó el área con un error de centésimas, que disminuye como $1/\sqrt{n}$.
- Como las rotaciones tienen **determinante 1**, conservan las áreas.

# Atlas de cónicas: equipo de ejemplo

Proyecto integrador del Taller de Cómputo (ENES Juriquilla, UNAM).

Análisis de la cónica $5x^2 - 6xy + 5y^2 - 8 = 0$ con Python, SymPy, NumPy, Matplotlib y Plotly.

- **Sitio web:** https://usuario.github.io/proyecto-conicas-ejemplo/
- **Autoras:** Evelia Coss y Haydeé Peruyero

## Cómo reproducir el sitio

1. Activar el entorno: `source ~/.venvs/quarto-python/bin/activate`
2. Renderizar: `quarto render`
3. El sitio queda en la carpeta `docs/`.

67.8.3 Cómo usar el ejemplo

  1. Descarguen el .zip y descomprímanlo.
  2. En RStudio, abran la carpeta como proyecto: File > Open Project in New Session… (o File > New Project > Existing Directory).
  3. Verifiquen que su entorno esté configurado (Configuraciones para usar Quarto con Python).
  4. Rendericen el sitio con Build > Render Website o, en la Terminal, con quarto render.
  5. Abran docs/index.html en el navegador y comparen con el sitio publicado.

Después, creen su propio proyecto (sección Estructura del sitio) con la cónica de su equipo, usando el ejemplo como referencia.

67.12 Preguntas frecuentes

¿Podemos usar inteligencia artificial? Sí, como apoyo para entender errores o ideas, pero deben entender y poder explicar cada línea de su código en la presentación. Indiquen en las referencias si la usaron y para qué.

¿Qué hacemos si quarto render falla? Lean el último mensaje de error y busquen la solución en Configuraciones para usar Quarto con Python. Si aparece ModuleNotFoundError, revisen QUARTO_PYTHON.

¿Cómo sabemos si nuestra forma canónica es correcta? Con la Parte 5: si la curva canónica girada con la matriz de rotación coincide con la ecuación original y el error es casi cero, el análisis es correcto.

¿Cómo trabajamos varias personas sin romper el código? Antes de empezar a trabajar, hagan git pull; al terminar, git add, git commit y git push. Si es posible, cada integrante trabaja en una página distinta.
