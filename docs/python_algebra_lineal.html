59  Álgebra lineal con NumPy

Fecha: 05 de noviembre, 2026

En el capítulo de NumPy vimos que las operaciones con arreglos se hacen elemento a elemento. Pero en álgebra lineal los vectores y las matrices tienen sus propias operaciones: el producto punto, el producto de matrices, el determinante, la inversa… NumPy las incluye en el operador @ y en el módulo np.linalg (linear algebra).

En este capítulo veremos:

  • Vectores: producto punto, norma y ángulo entre vectores.
  • El producto de matrices y la diferencia entre @ y *.
  • La transpuesta y la matriz identidad.
  • El determinante y la matriz inversa.
  • Cómo resolver sistemas de ecuaciones lineales.
Código 
import numpy as np

59.1 Resumen de operaciones

Operación Notación matemática NumPy
Producto punto \(\mathbf{u} \cdot \mathbf{v}\) u @ v o np.dot(u, v)
Norma (longitud) \(\lVert \mathbf{v} \rVert\) np.linalg.norm(v)
Producto de matrices \(AB\) A @ B
Transpuesta \(A^T\) A.T
Identidad \(I_n\) np.eye(n)
Determinante \(\det(A)\) np.linalg.det(A)
Inversa \(A^{-1}\) np.linalg.inv(A)
Resolver \(Ax = b\) \(x = A^{-1}b\) np.linalg.solve(A, b)

59.2 Vectores

En NumPy un vector es un arreglo de una dimensión. La suma de vectores y el producto por un escalar ya los conocemos, porque son operaciones elemento a elemento:

Código 
u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

print("u + v =", u + v)
u + v = [5 7 9]
Código 
print("2u =", 2 * u)
2u = [2 4 6]

59.2.1 Producto punto

El producto punto multiplica los elementos en la misma posición y suma los resultados:

\[\mathbf{u} \cdot \mathbf{v} = u_0 v_0 + u_1 v_1 + \dots + u_{n-1} v_{n-1}\]

Código 
print("u * v =", u * v)                 # Elemento a elemento: [ 4 10 18]
u * v = [ 4 10 18]
Código 
print("(u * v).sum() =", (u * v).sum()) # Sumamos: 4 + 10 + 18 = 32
(u * v).sum() = 32
Código 
print("u @ v =", u @ v)                 # Producto punto en un solo paso
u @ v = 32
Código 
print("np.dot(u, v) =", np.dot(u, v))   # Equivalente
np.dot(u, v) = 32

59.2.2 Norma de un vector

La norma es la longitud del vector: \(\lVert \mathbf{v} \rVert = \sqrt{v_0^2 + v_1^2 + \dots + v_{n-1}^2}\).

Código 
w = np.array([3, 4])

print(np.sqrt((w ** 2).sum()))   # Con la fórmula: √(9 + 16) = 5
5.0
Código 
print(np.linalg.norm(w))         # Con NumPy
5.0

59.2.3 Ángulo entre vectores

Con el producto punto y las normas obtenemos el ángulo \(\theta\) entre dos vectores:

\[\cos \theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\lVert \mathbf{u} \rVert \, \lVert \mathbf{v} \rVert}\]

Para despejar \(\theta\) usamos np.arccos() (la función inversa del coseno, en radianes) y np.rad2deg() para pasar a grados:

Código 
a = np.array([1, 0])
b = np.array([1, 1])

cos_theta = (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))
theta = np.arccos(cos_theta)

print("cos θ =", cos_theta)
cos θ = 0.7071067811865475
Código 
print("θ en radianes =", theta)
θ en radianes = 0.7853981633974484
Código 
print("θ en grados =", np.rad2deg(theta).round(2))
θ en grados = 45.0

Si \(\mathbf{u} \cdot \mathbf{v} = 0\), el ángulo es de 90°: los vectores son perpendiculares (ortogonales).

59.3 Producto de matrices

El producto de matrices \(AB\) no es elemento a elemento: cada entrada \((i, j)\) del resultado es el producto punto de la fila \(i\) de \(A\) con la columna \(j\) de \(B\). En NumPy se escribe con @:

Código 
A = np.array([[2, 1],
              [1, 3]])
B = np.array([[1, 0],
              [2, 1]])

print("A @ B =\n", A @ B)          # Producto de matrices
A @ B =
 [[4 1]
 [7 3]]
Código 
print("A * B =\n", A * B)          # Producto elemento a elemento (¡diferente!)
A * B =
 [[2 0]
 [2 3]]

Por ejemplo, la entrada \((0, 0)\) de A @ B es la fila 0 de A por la columna 0 de B: \(2 \cdot 1 + 1 \cdot 2 = 4\).

Importante

A * B multiplica elemento a elemento; el producto de matrices que conoces del álgebra lineal es A @ B.

El orden importa: en general \(AB \neq BA\).

Código 
print("A @ B =\n", A @ B)
A @ B =
 [[4 1]
 [7 3]]
Código 
print("B @ A =\n", B @ A)
B @ A =
 [[2 1]
 [5 5]]

Las formas deben ser compatibles: una matriz de \(m \times n\) solo se puede multiplicar por una de \(n \times p\), y el resultado es de \(m \times p\). El número de columnas de la primera debe ser igual al número de filas de la segunda:

Código 
C = np.array([[1, 2, 0],
              [0, 1, 3]])          # forma (2, 3)
D = np.array([[2, 1],
              [0, 1],
              [1, 0]])             # forma (3, 2)

print((C @ D).shape)   # (2, 3) @ (3, 2) -> (2, 2)
(2, 2)
Código 
print((D @ C).shape)   # (3, 2) @ (2, 3) -> (3, 3)
(3, 3)
Código 
C @ C   # (2, 3) @ (2, 3): 3 ≠ 2 -> ValueError
ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 2 is different from 3)

59.4 Transpuesta e identidad

La transpuesta \(A^T\) intercambia filas por columnas. La identidad \(I_n\) tiene unos en la diagonal y ceros fuera de ella; cumple \(AI = IA = A\):

Código 
print("C =\n", C)
C =
 [[1 2 0]
 [0 1 3]]
Código 
print("C^T =\n", C.T)              # forma (2, 3) -> (3, 2)
C^T =
 [[1 0]
 [2 1]
 [0 3]]
Código 
I = np.eye(2)
print("A @ I =\n", A @ I)          # Igual a A
A @ I =
 [[2. 1.]
 [1. 3.]]

59.5 Determinante e inversa

Código 
print("det(A) =", np.linalg.det(A))
det(A) = 5.000000000000001
Código 
print("A^-1 =\n", np.linalg.inv(A))
A^-1 =
 [[ 0.6 -0.2]
 [-0.2  0.4]]

El determinante de A es exactamente \(2 \cdot 3 - 1 \cdot 1 = 5\), pero NumPy da 5.000000000000001. Es el mismo problema de precisión limitada que vimos con \(\sin(\pi)\) en el capítulo de NumPy: por eso conviene redondear con round().

Para comprobar que la inversa es correcta, multiplicamos \(AA^{-1}\), que debe dar la identidad. Como los decimales son aproximados, comparamos con np.allclose(), que responde True si todos los elementos son casi iguales:

Código 
producto = A @ np.linalg.inv(A)
print(producto)                        # -5.55e-17 en lugar de 0
[[ 1.00000000e+00  0.00000000e+00]
 [-5.55111512e-17  1.00000000e+00]]
Código 
print(np.allclose(producto, np.eye(2)))
True
Advertencia

Una matriz con \(\det(A) = 0\) es singular: no tiene inversa y NumPy da un error LinAlgError.

Código 
S = np.array([[1, 2],
              [2, 4]])      # La fila 1 es el doble de la fila 0
print("det(S) =", np.linalg.det(S))
det(S) = 0.0
Código 
np.linalg.inv(S)
numpy.linalg.LinAlgError: Singular matrix

59.6 Sistemas de ecuaciones lineales

Un sistema de ecuaciones lineales se escribe en forma matricial como \(Ax = b\), donde \(A\) es la matriz de coeficientes, \(x\) el vector de incógnitas y \(b\) el vector de términos independientes. Por ejemplo:

\[\begin{cases} 2x + y = 5 \\ x + 3y = 10 \end{cases} \quad \Longrightarrow \quad \underbrace{\begin{pmatrix} 2 & 1 \\ 1 & 3 \end{pmatrix}}_{A} \begin{pmatrix} x \\ y \end{pmatrix} = \underbrace{\begin{pmatrix} 5 \\ 10 \end{pmatrix}}_{b}\]

Si \(\det(A) \neq 0\), el sistema tiene solución única \(x = A^{-1}b\). En la práctica se usa np.linalg.solve(A, b), que es más rápido y más preciso que calcular la inversa:

Código 
b = np.array([5, 10])

x = np.linalg.solve(A, b)
print("Solución:", x)
Solución: [1. 3.]
Código 
print("Comprobación A @ x:", A @ x)
Comprobación A @ x: [ 5. 10.]
Código 
print(np.allclose(A @ x, b))
True

59.7 Ejercicios

Resuelve los ejercicios en los editores interactivos. Recuerda que lo que escribas no se guarda al recargar la página. La primera vez que ejecutes un editor, NumPy puede tardar unos segundos en cargar.

59.7.1 Ejercicio 1. Producto de matrices

  1. Calcula el producto de matrices \(CD\) y guárdalo en CD.
  2. Imprime la forma de D @ C. ¿Por qué es distinta de la de CD?
  3. Deja CD en la última línea.
NotaPista

El producto de matrices se escribe C @ D. La forma de un arreglo está en su atributo .shape.

TipSolución 
import numpy as np

C = np.array([[1, 2, 0],
              [0, 1, 3]])
D = np.array([[2, 1],
              [0, 1],
              [1, 0]])

CD = C @ D
print("Forma de D @ C:", (D @ C).shape)   # (3, 3): (3, 2) @ (2, 3)
CD                                        # [[2 3] [3 1]], forma (2, 2)

59.7.2 Ejercicio 2. Ángulo entre vectores

Calcula el ángulo, en grados, entre los vectores \(\mathbf{u} = (1, 2, 2)\) y \(\mathbf{v} = (2, 1, -2)\), y déjalo en la última línea. ¿Qué tipo de vectores son?

NotaPista

cos_theta = (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v)). Después usa np.arccos() y np.rad2deg().

TipSolución 
import numpy as np

u = np.array([1, 2, 2])
v = np.array([2, 1, -2])

cos_theta = (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v))   # 0 / 9 = 0
theta_grados = np.rad2deg(np.arccos(cos_theta))
theta_grados                                                     # 90.0: perpendiculares

59.7.3 Ejercicio 3. Sistema de ecuaciones

Resuelve el sistema de ecuaciones:

\[\begin{cases} 2x + y - z = 3 \\ x - y + 2z = 5 \\ 3x + 2y + z = 10 \end{cases}\]

  1. Escribe la matriz de coeficientes A y el vector de términos independientes b.
  2. Verifica que el sistema tiene solución única calculando \(\det(A) \neq 0\).
  3. Resuelve el sistema con np.linalg.solve() y deja la solución en la última línea.
  4. Comprueba la solución calculando A @ solucion, que debe ser igual a b.
NotaPista

Cada fila de A contiene los coeficientes de una ecuación: la primera es [2, 1, -1]. El vector b es [3, 5, 10]. Después usa np.linalg.solve(A, b).

TipSolución 
import numpy as np

A = np.array([[2, 1, -1],
              [1, -1, 2],
              [3, 2, 1]])
b = np.array([3, 5, 10])

print("det(A) =", np.linalg.det(A))   # -10.0 (aprox.), distinto de 0

solucion = np.linalg.solve(A, b)
print("Solución:", solucion)           # [2. 1. 2.]
print("Comprobación A @ solución:", A @ solucion)
solucion

59.8 Resumen

Tema Idea clave
Vectores Producto punto u @ v, norma np.linalg.norm(v), ángulo con np.arccos().
Producto de matrices A @ B; las formas \((m, n)\) y \((n, p)\) dan \((m, p)\); en general \(AB \neq BA\).
@ vs. * @ es el producto de matrices; * es elemento a elemento.
Transpuesta e identidad A.T, np.eye(n).
Determinante e inversa np.linalg.det(A), np.linalg.inv(A); si \(\det(A) = 0\) no hay inversa.
Sistemas de ecuaciones np.linalg.solve(A, b); comprueba con np.allclose(A @ x, b).
