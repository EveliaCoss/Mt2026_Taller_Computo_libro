73  🔢 Proyecto alternativo: atlas de números primos

📅 Inicio: jueves 26 de noviembre de 2026 · Entrega del sitio: jueves 3 de diciembre de 2026 · Presentaciones: martes 8 de diciembre de 2026

Importante¿Para quién es este proyecto?

Este proyecto es la alternativa individual al proyecto integrador de cónicas para quien tomó todo el Taller de Cómputo pero no cursa Geometría Analítica. Integra las mismas herramientas del curso, pero el tema es la teoría de números: no necesitas nada de cónicas ni de rotación de ejes. Los detalles (variantes, partes y rúbrica) pueden cambiar mientras terminamos de definirlo.

Los números primos son los “átomos” de los enteros: todo entero mayor que 1 se escribe como producto de primos de una sola forma. Parecen aparecer al azar, pero esconden patrones que los matemáticos llevan siglos estudiando. En este proyecto construirás un sitio web que explore esos patrones usando todo lo que aprendimos en el Taller de Cómputo: Python, funciones, NumPy, SymPy, visualización, álgebra lineal, números aleatorios, Quarto, Git y GitHub.

Nota🧭 Este capítulo es una guía, no un ejemplo resuelto

Aquí no encontrarás las respuestas. Para cada parte del proyecto te decimos qué debes entregar y 📖 dónde estudiarlo en el libro. El único código que te damos es el punto de partida de funciones.py: incompleto y con errores que tú debes corregir.

73.1 Objetivo

Construir un atlas de los números primos hasta un número \(N\): encontrarlos con la criba de Eratóstenes, contarlos y compararlos con el teorema de los números primos, visualizar sus patrones (la espiral de Ulam, las “carreras” de primos y la conjetura de Goldbach), estimar \(\pi\) con números aleatorios a partir de la probabilidad de que dos enteros no tengan divisores en común, y publicar todo en un sitio web de Quarto en GitHub Pages.

import numpy as np


# ⚠️ Estas funciones están INCOMPLETAS y tienen ERRORES A PROPÓSITO.
#    1. Completa cada ______.

def es_primo(n):
    """Regresa True si n es primo. Solo prueba los divisores d con d² ≤ n."""
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5)):                # 🐞 ¿Se prueba el divisor √n? Pruébala con 49.
        if n % d == 0:
            return False
    return True


def criba(N):
    """Arreglo de NumPy con todos los primos p ≤ N (criba de Eratóstenes)."""
    es_p = np.ones(N + 1, dtype=bool)                # es_p[k] dice si k "sigue siendo" candidato a primo
    es_p[:2] = ______                                # 0 y 1 no son primos
    for p in range(2, int(N ** 0.5) + 1):
        if es_p[p]:
            es_p[p * p :: p] = True                  # 🐞 ¿Qué hay que hacer con los múltiplos de p?
    return np.arange(N + 1)[es_p]


def mcd(a, b):
    """Máximo común divisor de a y b con el algoritmo de Euclides."""
    while b != 0:
        a, b = b, a // b                             # 🐞 Euclides usa el residuo, no el cociente.
    return ______                                    # Cuando b llega a 0, ¿cuál es el mcd?


def contar_primos(x, primos):
    """π(x): cuántos primos del arreglo `primos` son menores o iguales que x."""
    return np.sum(primos < x)                        # 🐞 Si x es primo, ¿se cuenta? Pruébala con x = 7.
Advertencia🐞 Encuentra y corrige los errores

Las líneas marcadas con 🐞 tienen al menos un error cada una, y todos son errores silenciosos: el código se ejecuta sin avisar, pero da resultados incorrectos. Por eso no basta con que corra: escribe las pruebas y corrige hasta que todas pasen. En tu entrega, funciones.py no debe tener ningún ______ ni ningún 🐞. Repasa errores silenciosos y leer los mensajes de error.

La criba de Eratóstenes es nueva: en vez de probar cada número por separado, empieza suponiendo que todos son primos y va tachando los múltiplos de cada primo. Con NumPy, tachar todos los múltiplos de p es una sola asignación con rebanado (es_p[p * p :: p] = ...). Puedes agregar más funciones si te ayudan.

73.5.3 Parte 3. Análisis con SymPy

Qué hacer:

  1. Contar primos. Con tu criba() y tu contar_primos(), calcula \(\pi(x)\) para \(x = 10, 100, 1\,000, \dots\) hasta \(N\), y compruébalo con sp.primepi(x) de SymPy.
  2. El teorema de los números primos. Este teorema dice que \(\pi(x) \sim \dfrac{x}{\ln x}\), es decir, que el cociente de ambos tiende a 1. Haz una tabla con \(\pi(x)\), \(\dfrac{x}{\ln x}\), la integral logarítmica \(\operatorname{Li}(x)\) (sp.li(x)) y los cocientes \(\pi(x) \big/ \dfrac{x}{\ln x}\). Calcula con SymPy el límite \(\displaystyle\lim_{x \to \infty} \frac{\operatorname{Li}(x)}{x / \ln x}\) y explica qué dice tu tabla: ¿cuál de las dos aproximaciones es mejor?
  3. La carrera de primos módulo \(m\). Clasifica tus primos según su residuo al dividirlos entre el \(m\) de tu variante y cuenta cuántos hay en cada clase. Identifica qué residuos tienen muchos primos y cuáles tienen a lo más uno, y explica con tus palabras por qué pasa eso (piensa en el máximo común divisor del residuo y \(m\)). ¿Qué clase “va ganando” la carrera?
  4. Huecos y gemelos. Calcula los huecos entre primos consecutivos (la diferencia \(p_{k+1} - p_k\)), el hueco más grande hasta \(N\) y cuántas parejas de primos gemelos (hueco igual a 2) hay.

📖 Dónde estudiarlo:

  • SymPy: sustituir y evaluar, límites y de SymPy a LaTeX.
  • NumPy: funciones matemáticas (np.log(), np.diff()), máscaras booleanas y funciones estadísticas.
  • El mapa de calor de la aritmética modular: residuos con %.

sp.primepi(), sp.li() y np.diff() son nuevas: consulta su ayuda con help() o en la documentación.

73.5.5 Parte 5. La espiral de Ulam: una matriz de primos

Qué hacer:

  1. Construir la espiral. Escribe los enteros \(1, 2, 3, \dots\) en una matriz cuadrada de NumPy (por ejemplo, de \(201 \times 201\)), empezando en el centro y avanzando en espiral: un paso a la derecha, uno hacia arriba, dos a la izquierda, dos hacia abajo, tres a la derecha, tres hacia arriba… Después crea una matriz de True/False que diga en qué casillas hay un primo y dibújala como mapa de calor. Explica en tu sitio cómo recorriste la espiral.
  2. El polinomio de una diagonal. En la espiral se ven diagonales con muchos primos. Elige una, toma tres de sus números consecutivos y encuentra el polinomio \(f(n) = an^2 + bn + c\) que los genera planteando y resolviendo un sistema de ecuaciones de \(3 \times 3\) en forma matricial (con NumPy o con matrices de SymPy). Explica tu estrategia: qué representa cada fila del sistema y por qué tres puntos bastan. Comprueba con sp.isprime() cuántos de los primeros valores de \(f(n)\) son primos.
  3. El polinomio de Euler. Comprueba con SymPy que \(n^2 + n + 41\) es primo para \(n = 0, 1, \dots, 39\), y explica por qué no puede ser primo para \(n = 40\) (factoriza con sp.factorint()).

📖 Dónde estudiarlo:

  • Dimensiones de un arreglo, indexación de arreglos de dos o más dimensiones y máscaras booleanas.
  • Mapas de calor en 2D y mapa de calor con plt.imshow().
  • Sistemas de ecuaciones lineales y matrices en SymPy.
  • Ciclos while y ciclos anidados.

73.5.6 Parte 6. La conjetura de Goldbach

Qué hacer: la conjetura de Goldbach (1742) dice que todo número par mayor que 2 es la suma de dos primos; por ejemplo, \(28 = 5 + 23 = 11 + 17\). Nadie la ha demostrado. Comprueba numéricamente que se cumple para todos los pares de 4 a \(G\), y cuenta de cuántas formas se puede escribir cada par. Grafica ese número de formas contra el par (el “cometa de Goldbach”) e interpreta el resultado: ¿por qué tu comprobación no es una demostración?

📖 Dónde estudiarlo:

  • for con condicionales, acumuladores y contadores y break.
  • Máscaras booleanas: con un arreglo es_p de True/False, es_p[n - primos] revisa muchos números de una sola vez.
  • Ciclos for vs. NumPy.

73.5.7 Parte 7. \(\pi\) con el método de Monte Carlo

Qué hacer: dos enteros son coprimos si su máximo común divisor es 1. Se sabe que la probabilidad de que dos enteros elegidos al azar sean coprimos es

\[P = \frac{1}{\displaystyle\sum_{k=1}^{\infty} \frac{1}{k^2}}.\]

  1. Calcula con SymPy el valor exacto de la suma y, con él, el de \(P\).
  2. Estima \(P\) eligiendo muchas parejas de enteros al azar (por ejemplo, entre 1 y \(10^6\)) y contando cuántas son coprimas con tu mcd(). Despeja \(\pi\) de tu estimación.
  3. Haz una gráfica de convergencia que muestre cómo se acerca tu estimación de \(\pi\) al valor real al aumentar el número de parejas.

📖 Dónde estudiarlo:

  • Números aleatorios con NumPy, estimar \(\pi\) lanzando “dardos” y ¿qué tan rápido converge?.
  • Documentar simulaciones en Quarto.
  • Sumas con SymPy y el reto final de SymPy: dos series famosas.

📖 Dónde estudiarlo:

73.6.1 Calentamiento 1. Primos más rápido

En Funciones la función es_primo() probaba todos los divisores de 2 a \(n - 1\). Si \(n = a \cdot b\) con \(a \le b\), entonces \(a^2 \le n\): basta probar los divisores \(d\) con \(d^2 \le n\). Completa la función con esa idea.

NotaPista

La condición del while debe decir “mientras \(d^2 \le n\)”. Repasa la potencia en Introducción a Python y los operadores de comparación. ¿Qué pasa con 49 si usas < en vez de <=?

73.6.2 Calentamiento 2. El algoritmo de Euclides

El algoritmo de Euclides calcula el máximo común divisor con una idea: \(\operatorname{mcd}(a, b) = \operatorname{mcd}(b, r)\), donde \(r\) es el residuo de dividir \(a\) entre \(b\). Se repite hasta que el segundo número sea 0. Por ejemplo,

\[\operatorname{mcd}(48, 18) = \operatorname{mcd}(18, 12) = \operatorname{mcd}(12, 6) = \operatorname{mcd}(6, 0) = 6.\]

NotaPista

En cada paso, el nuevo a es el b de antes y el nuevo b es el residuo (operador %). Escribirlo en una sola línea, a, b = ..., ..., evita perder el valor viejo de a. Cuando b llega a 0, el mcd es el otro número.

73.9 Preguntas frecuentes

¿Puedo usar sp.isprime() o np.gcd() en lugar de mis funciones? Puedes usarlas para comprobar tus funciones (por ejemplo, en tus pruebas con assert), pero los resultados del proyecto deben salir de tus funciones de funciones.py.

Mi criba tarda mucho. Revisa que tache los múltiplos con rebanado de NumPy (es_p[p * p :: p]) y no con un ciclo sobre cada múltiplo, y que el ciclo exterior se detenga en \(\sqrt{N}\).

¿Puedo usar inteligencia artificial? Sí, como apoyo para entender errores o ideas, pero debes entender y poder explicar cada línea de tu código en la presentación. Indica en las referencias si la usaste y para qué.

¿Qué hago si quarto render falla? Lee el último mensaje de error y busca la solución en Configuraciones para usar Quarto con Python. Si aparece ModuleNotFoundError, revisa QUARTO_PYTHON.
